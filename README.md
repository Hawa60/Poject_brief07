## Project brief description
The **Job Portal System** is a web-based recruitment platform that connects companies and job seekers in a centralized system. It enables companies to post job vacancies and manage applications, while applicants can search for jobs, apply online, and track their application status. Administrators oversee users, companies, and system activities. Developed using the **MERN Stack**, the system provides secure authentication, role-based access control, and an efficient recruitment process through a responsive and user-friendly interface.

React.js, Node.js, Express.js
